## 正本

- [`完成イメージ.md`](完成イメージ.md)：利用者から見た完成状態
- [`WBS.md`](WBS.md)：構想から完成までの作業と現在地
- [`要件.md`](要件.md)：初版で満たす要件、対象外、受入条件（合意済み）
- [`方式比較.md`](方式比較.md)：技術方式の比較と採用理由（合意済み）

要件、設計、試験、運用の文書は、それぞれの工程で必要な正本を決めます。小さく保てる
場合はREADMEなどへ統合し、同じ情報を複数の文書へ重複させません。

## 保管方針

- プロジェクト本体と恒久文書：このディレクトリ
- 調査メモや一時成果物：必要になった時点でプロジェクト内に用途を明示して置く
- 秘密情報：プロジェクト文書やGit管理対象には保存しない
- ダウンロードした実データ：設計時に保存場所と取扱いを決める

呼び名と恒久フォルダは「ろばみみ打刻」とし、ワークスペース直下のこのディレクトリを正本とします。
